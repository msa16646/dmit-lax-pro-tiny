## 1 核 2G、20G 硬盘、1TB 双向，卡在哪

先把最容易被忽略的一条说清楚：**1TB 是双向计费**，出站和入站都算。只计算出站流量的套餐，传同样多的数据，账面上会好看不少。公开测评里有个具体例子，跑一次完整的 YABS 带宽测试就消耗了接近 100G 流量。按这个量级，纯测速跑十次，一个月的额度就没了。

额度用完之后不会停机。DMIT 的处理方式是把端口限速到 4Mbps，机器继续在线，SSH 也还能连。4Mbps 大约是 500KB/s，够你登上去处理事务、拉个小文件，但指望它继续对外服务就不现实。如果当月就必须恢复满速，官方文档写明多数标准套餐支持付费重置流量，费用折算下来大致相当于一个月月费。

20GB 系统盘是第二个硬约束。装完系统和基础环境，能自由支配的空间还要再少一截。放几个静态站、跑个 API 没问题，存日志、备份、图片附件很快就会顶到天花板。

1 核 CPU 决定了它跑不了什么：持续编译、大型数据库、多个重型容器，这些会让单核长期跑满。跑个人网站、博客、反向代理、机器人、监控面板、小型后台接口，是它的舒适区。

需要更多空间或更多核心，官方文档里有一条不显眼的说明：多数套餐允许追加内存和存储，而 IP 和 CPU 核心只有少数套餐支持（LAX Pro 就在支持名单里）。这意味着理论上你能在 TINY 上加点内存续命，但追加成本要开工单问，未必比直接升套餐便宜。

## 线路怎么走，IPv4 和 IPv6 不是一回事

LAX Pro 的 IPv4 路由结构在多个来源上是一致的：

- 电信去程：CN2 GIA（AS4809）
- 联通去程：直连 AS4837
- 移动去程：经香港 CMI（AS58453）
- 三网回程：CN2 GIA（AS4809）

回程全走 CN2 GIA 是这条产品线的核心卖点，也是它比 EB、T1 贵的原因。公开测评汇总给出的中国大陆三网延迟大致在 140–180ms 区间，晚高峰波动不大。

IPv6 的说法有分歧。一部分资料称 IPv6 回程同样走 CN2 GIA，更近期的实测记录则显示 IPv4 走 CN2 GIA、IPv6 走 9929 / CMIN2。稳妥的理解是：**纯 CN2 GIA 的保证只覆盖 IPv4，IPv6 走的是次一级的优化线路**。如果你的业务强依赖 IPv6 回程质量，下单前值得先确认当前平台的实际路由。
